## 🚀 Getting Started

### Prerequisites
- A web browser (Chrome, Firefox, Safari, Edge)
- A web server (for deployment)
- Text editor for customization

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/siddarbadofofficialroblox7-wq/sidd_brozx_smp_website.git
cd sidd_brozx_smp_website
```

2. **Open locally**
```bash
# Simply open index.html in your browser
open index.html
```

Or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js http-server
npx http-server
```

3. **Customize the website**
- Edit `index.html` to change content
- Modify `styles.css` for colors and styling
- Update `script.js` for functionality

## ⚙️ Customization

### Update Social Media Links

In `script.js`, update these links:

```javascript
// Line ~85: Discord
window.open('https://discord.gg/yourdiscord', '_blank');

// Line ~91: YouTube
window.open('https://youtube.com/yourvideo', '_blank');

// Line ~96-103: Community buttons
// Update the URLs for Discord, YouTube, and Instagram
```

### Change Colors

In `styles.css`, modify the CSS variables:

```css
:root {
    --primary-color: #2ecc71;      /* Green accent */
    --secondary-color: #1a1a1a;    /* Dark background */
    --text-color: #ffffff;          /* White text */
}
```

### Modify Content

Edit the HTML in `index.html`:
- Update server name and description
- Change player count
- Modify feature descriptions
- Update rules
- Add your own content
